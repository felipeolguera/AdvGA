PRD Lorraine Arclight — Play Guide

Fire / Arcane Warrior shell: champion attacks, Fire discard into the Sword, and Arcane static counters.

Open AdvGA Fire aggro Water aggro Wind aggro PRD Lorraine PRD Dante
Load in AdvGA: Deck Builder → Load Lorraine (Fire/Arcane). Standard shell: Material 12 · Main 60 · Sideboard 15.

Game plan

Survive early with cheap Fire allies and Emberslash, then level Lorraine while Arcane pieces stack static counters so combat hits drip extra damage and Fire discards grow your Sword.

Champion line

Spirit of Fire

CHAMPION · FIRE · SPIRIT · 0 memory · Lv 0

Level 0 opener — On Enter draw seven.

Lorraine, Wandering Warrior

CHAMPION · NORM · WARRIOR · 1 memory · Lv 1

L1 — On Enter tries to materialize a memory-cost 0 weapon (this shell’s Sword is memory 1, so often pay for AquaTech Blade X yourself).

Lorraine, Honed Operative

CHAMPION · NORM · WARRIOR · 2 memory · Lv 2

L2 — Filter memory; advanced-element draws can juice a Sword’s durability.

Lorraine, Arclight Saber

CHAMPION · ARCANE · WARRIOR · 3 memory · Lv 3

L3 payoff — flood static counters from LV + Arcane in banishment; Arcane combat can spend counters for pings.

Opening checklist

  • Spirit of Fire → cheap Warrior curve (Fulgurite / Emberslash / Courier / Tindered / Insurgent).
  • Level L1 for life + Class Bonus; materialize AquaTech Blade X when you can attack.
  • Attach FlameTech BladeCore, then discard Fire to grow durability.
  • Level to L3 once Arcane pieces are in banishment so static On Enter is real.

Common mistakes

  • Holding L3 forever without Arcane in banishment — still better to level than stall three turns.
  • Playing BladeCore with no Sword out.
  • Spending every static on Triboelectric right before an Arcane attack turn.
  • Casting Leran with a full grip — it wants low influence.
