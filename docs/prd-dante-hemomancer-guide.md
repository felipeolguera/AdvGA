# PRD Dante Hemomancer — Play Guide

Water / Exia Mage suggestion for **.asphodel/paradise (PRD)**.

**In AdvGA:** Deck Builder → Load Dante (Water/Exia) · [HTML guide](../public/guides/prd-dante-hemomancer.html)

## Game plan

Build an **Elysian** board, empower Aenean Spells, and use sacrifice/recover while Dante levels into Hemomancer.
